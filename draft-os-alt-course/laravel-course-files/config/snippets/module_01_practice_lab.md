## Изучение дистрибутива изнутри

Работайте в контейнере под пользователем `student`.

Правило простое: **одно задание — один файл** в домашнем каталоге:

- задание 1 → `~/1.txt`
- задание 2 → `~/2.txt`
- задание 3 → `~/3.txt`
- задание 4 → `~/4.txt`

Пишите коротко и по сути. Лишняя разметка не нужна.

---

## Задание 1. Название и версия ОС

Определите название и версию ALT из системного файла выпуска.

В конце задания запишите правильный ответ в файл **`~/1.txt`**.

## Задание 2. Тип продукта по пакетам

Определите тип продукта по установленным пакетам (сервер/рабочая станция/education/СП и т.д.).

В конце задания запишите правильный ответ в файл **`~/2.txt`**.

## Задание 3. Графика и вывод о роли системы

Проверьте режим загрузки (target), наличие признаков графической среды и сделайте вывод о роли системы.

В конце задания запишите правильный ответ в файл **`~/3.txt`**.

## Задание 4. Архитектура и ядро

Определите архитектуру и строку ядра.

В конце задания запишите правильный ответ в файл **`~/4.txt`**.

---

## Сдача

На странице курса: **«Запустить контейнер»** → выполнить задания → **«Проверить результат»**.
Если нужно, исправьте файлы и проверяйте повторно.
Когда результат устраивает, нажмите **«Принять результат»**.
