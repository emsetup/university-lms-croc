## О чём эта инструкция

**Палитра команд** — поисковый launcher админки: вместо цепочки «главная → курсы → курс → модули» вы вводите название и переходите с клавиатуры. Состав пунктов **зависит от роли** — тестировщик не увидит сотрудников, инструктор — не Docker.

> **Зачем этот раздел:** при ежедневной работе с десятком экранов экономия 10–20 секунд на переход суммируется в часы. Особенно полезно при переключении между **Docker** и конкретной **практикой** модуля.

## Кому и когда нужно

Всем, кто работает в **`/adm`** с правом редактирования или просмотра курсов. Выучите **Ctrl+K** в первый день; на Mac — **⌘K**.

## Что вы делаете здесь и какой результат ожидать

Вы открываете палитру, вводите часть названия курса или раздела, выбираете стрелками, подтверждаете **Enter**. Результат — мгновенный переход на целевую страницу без ручного обхода меню.

## Пошаговая работа

1. **Нажмите Ctrl+K** (или кликните поле поиска с иконкой лупы в шапке **`/adm`**).
2. **Начните вводить** имя курса, «Docker», «Обучающиеся», «Настройки» — список отфильтруется.
3. **Стрелками** выделите нужный пункт (курс, раздел, действие).
4. **Enter** — переход; **Esc** — закрыть без навигации.
5. Если пункта нет — проверьте роль (нет прав) или опечатку в slug/названии.

## Элементы интерфейса

| Элемент | Зачем нужен | Как пользоваться | Что произойдёт |
|---------|-------------|------------------|----------------|
| **Ctrl+K** / **⌘K** | Горячая клавиша | Из любой страницы **`/adm`** | Открытие палитры |
| Поле поиска в шапке | То же без клавиатуры | Клик | Окно палитры |
| Строка ввода | Фильтр пунктов | Набор текста | Сужение списка |
| Список результатов | Цели перехода | Стрелки + Enter | Навигация |
| Пункты по роли | Безопасность | Автоматически | Нет лишних разделов |

## Частые вопросы

**Палитра пустая или мало пунктов.** У вас ограниченная роль (например, только назначенные курсы) — это нормально.

**Не находит курс по русскому названию.** Попробуйте slug или часть латиницы из **О курсе**.

**Работает ли на странице портала обучающегося?** Нет, только в контексте админки **`/adm`** (и связанных маршрутов).

> **Подсказка:** держите палитру «мышечной памятью» — Ctrl+K → имя модуля → Enter быстрее, чем воспроизводить путь из документации каждый раз.
