## О чём эта инструкция

Администратор и редактор курса могут **скачать вопросы** тестов, экзаменов и опросов в **Excel** (файл `.xls`) и **теорию** — в **Word** (файл `.doc`). Это удобно для ревью с коллегами, печати и копии вне портала. Импорт обратно из файла в портал **не** предусмотрен.

> **Зачем:** банк вопросов и текст теории живут в БД; выгрузка даёт читаемую копию без копирования из редактора вручную.

## Кому и когда нужно

Модератору, редактору, соавтору и тестировщику при приёмке модуля, согласовании банка вопросов или подготовке раздатки. Права те же, что на просмотр/редактирование соответствующего раздела в админке.

## Вопросы → Excel

Файл открывается в Excel и LibreOffice Calc (CSV с разделителем `;`, кодировка UTF-8).

**Колонки одного теста:** №, Тип, Текст, Варианты, Правильный ответ, Баллы.  
**Все вопросы курса:** те же колонки плюс Модуль, Раздел, Вид (тест / экзамен / опрос / финальная лаборатория).

### Где нажать

1. **Модули** → раздел **Тест** / **Экзамен** / **Опрос** → `>` → вкладка **Вопросы** → **Скачать Excel**.
2. Полноэкранный редактор вопросов (`/testy/...`) — кнопка **Скачать Excel** в шапке.
3. **Модули** (шапка страницы) или **Содержимое** — **Все вопросы (Excel)** — один файл по всему курсу.
4. Блок **Финальная лаборатория** — ссылка **Excel** рядом с вопросами финальной страницы.

Типы вопросов в выгрузке: один ответ, несколько ответов, сопоставление, открытый и смешанный (для опросов). В колонке «Правильный ответ» указаны правильные варианты (для админского ревью).

## Теория → Word

Файл `.doc` — HTML, который открывают Microsoft Word и LibreOffice Writer. Текст берётся из Markdown раздела (как в редакторе), с заголовком курса/модуля. Сложные блоки (Mermaid) могут отображаться упрощённо; картинки — по ссылкам на медиа портала.

### Где нажать

1. **Модули** → **Теория** → `>` → вкладка **Содержимое** → **Скачать Word**.
2. Классический редактор теории / **Контент модуля (БД)** — **Скачать Word** рядом с **Сохранить**.
3. **Содержимое** курса — **Все теории (Word ZIP)** (по одному `.doc` на модуль) и при необходимости **Markdown ZIP**.

## Частые вопросы

**Excel ругается на формат.** Откройте файл через «Файл → Открыть» или разрешите Excel преобразовать; содержимое — таблица с разделителем `;`.

**В Word нет диаграммы Mermaid.** В выгрузку попадает HTML без отрисовки схем — для схем смотрите Preview в редакторе или портал.

**Можно ли загрузить файл обратно?** Нет. Правки вносятся только в редакторах портала.

> **Подсказка:** перед публикацией модуля удобно выгрузить Excel с вопросами и Word с теорией и отдать рецензенту вне админки.
