## О чём эта инструкция

В редакторе курса можно **загружать изображения** и вставлять их в учебный текст: **теорию**, **практику**, **текст вопроса**, **варианты ответа** и пары **сопоставления**. Картинки хранятся в **библиотеке** портала (личные и привязанные к курсу), сжимаются на сервере и отображаются у обучающегося с поддержкой увеличения (lightbox).

> **Зачем этот раздел:** скриншоты интерфейса «Альт», схемы и иллюстрации в вопросах раньше требовали внешних ссылок или правки HTML. Теперь всё делается из админки — с предпросмотром размера до вставки.

## Кому и когда нужно

Модератору, редактору и соавтору курса при оформлении материалов. Нужен доступ к **`/adm`** и право редактировать контент курса. Отдельный пункт меню **Картинки** (`/adm/media`) — для просмотра всей своей библиотеки и загрузки без привязки к разделу.

## Где доступна вставка

| Место | Как открыть редактор | Кнопка |
|-------|----------------------|--------|
| **Теория** | **Модули** → **Теория** → `>` → вкладка **Содержимое** | Иконка изображения над полем Markdown |
| **Практика** | **Модули** → **Практика** → `>` → **Содержимое** | **Картинка** (иконка изображения в панели) |
| **Вопрос теста / экзамена / опроса** | **Модули** → раздел → `>` → **Вопросы** | **Картинка** у **Текста вопроса** и у каждого **варианта ответа** |
| **Вся библиотека** | Пункт **Картинки** в шапке админки | Загрузка и просмотр без вставки в текст |

## Пошаговая вставка

1. Откройте нужный редактор (теория, практика или вопрос).
2. Поставьте курсор в текст **туда, куда нужна картинка**.
3. Нажмите кнопку **Картинка** с иконкой изображения над полем текста — откроется **Библиотека картинок**.
4. **Загрузите** файл: перетащите в зону «Перетащите изображения сюда» или кликните для выбора. Форматы: **JPEG, PNG, GIF, WebP**, до **10 МБ**.
5. **Кликните по миниатюре** в сетке слева — справа появятся **Параметры вставки**.
6. Настройте:
   - **Альтернативный текст** — подпись и описание для доступности;
   - **Размер** — Полный / Большой (75%) / Средний (50%) / Малый (33%) / Мини (150 px);
   - **Выравнивание** — Блок / Центр / Слева / Справа (обтекание текстом).
7. Нажмите **Вставить** — в Markdown появится строка вида  
   `![подпись](/media/…-uuid… "w=150px;align=center")`.
8. **Сохраните** раздел (**Сохранить изменения**).
9. Проверьте **Просмотр** на вкладке **Содержимое** курса или кнопкой **Просмотр** в редакторе раздела.

![Библиотека картинок с параметрами вставки](/images/docs/media-library-insert.png)

## Примеры по типам разделов

### Теория

В панели форматирования над полем Markdown есть кнопка с иконкой изображения. После вставки в тексте остаётся Markdown — это нормально: при показе обучающемуся картинка рендерится автоматически.

![Вставка в теорию](/images/docs/media-insert-theory.png)

### Вопросы теста и экзамена

Картинку можно вставить **в формулировку вопроса** и в **любой вариант ответа** (кнопка **Картинка** у соответствующего поля). Удобно для задач «что на скриншоте?» или схем с подписями.

![Вставка в вопрос теста](/images/docs/media-insert-quiz.png)

### Предпросмотр

На вкладке **Содержимое** нажмите **Просмотр** у нужного раздела — откроется окно «как у обучающегося». Размер и выравнивание должны совпадать с настройками при вставке; по клику на крупное изображение открывается полноэкранный просмотр.

![Предпросмотр вопроса с миниатюрой](/images/docs/media-preview-quiz.png)

## Вкладки библиотеки

| Вкладка | Содержимое |
|---------|------------|
| **Мои** | Все картинки, которые вы загрузили (включая вставленные в любой курс) |
| **Этот курс** | Изображения, загруженные с привязкой к текущему курсу (видна только при открытии библиотеки из редактора курса) |

При загрузке из редактора курса файл автоматически связывается с этим курсом и попадает в вашу личную библиотеку.

## Размеры и выравнивание

| Размер | Поведение у обучающегося |
|--------|---------------------------|
| **Полный** | На всю ширину текстового блока (с ограничением по экрану) |
| **Большой** | До 75% ширины блока |
| **Средний** | До 50% |
| **Малый** | До 33% |
| **Мини** | До 150 px по ширине; для иконок и мелких скриншотов в вопросах |

**Выравнивание «Слева» / «Справа»** — текст обтекает картинку; **«Центр»** — блок по центру; **«Блок»** — на всю доступную ширину контейнера без обтекания.

Параметры сохраняются в Markdown в кавычках после ссылки на `/media/{uuid}` — при необходимости их можно поправить вручную (`w=50;align=right` и т.п.).

## Элементы интерфейса

| Элемент | Зачем нужен |
|---------|-------------|
| Зона перетаскивания | Быстрая загрузка одного или нескольких файлов |
| Сетка миниатюр | Выбор уже загруженной картинки |
| **Параметры вставки** | Предпросмотр, alt, размер, выравнивание |
| **Вставить** | Вставка Markdown в позицию курсора |
| **Картинки** в меню `/adm` | Общая библиотека без привязки к разделу |

## Частые вопросы

**В редакторе вижу код `![...](/media/...)`, а не картинку.** Так и задумано: поле редактирования — Markdown. Картинка видна в **Просмотре** и у обучающегося после сохранения.

**Загрузил «Мини», а в предпросмотре было большое.** Обновите страницу после деплоя портала; в предпросмотре должны подключаться стили медиа. Если в Markdown нет `"w=…"` в кавычках — вставьте картинку заново с нужным размером.

**Можно ли вставить одну картинку в несколько разделов?** Да: откройте библиотеку, выберите уже загруженный файл на вкладке **Мои** или **Этот курс** и вставьте снова.

**Видят ли картинки все обучающиеся?** Изображения курса доступны записанным на этот курс обучающимся и сотрудникам с доступом к контенту. Личные загрузки без привязки к курсу — только вам в админке, пока вы не вставите их в опубликованный материал курса.

**Двойной клик по миниатюре** в библиотеке вставляет картинку с текущими параметрами без нажатия **Вставить**.

> **Подсказка:** для длинных скриншотов в теории используйте **Средний** или **Большой** размер; для иконок и фрагментов UI в вопросах — **Мини**. Всегда заполняйте **альтернативный текст** — он показывается под картинкой и важен для доступности.
