## О чём эта инструкция

Вкладка **Модули** — скелет курса: последовательность модулей (M1, M2, …) и внутри каждого — **разделы** (теория, тест, практика, экзамен, опрос), которые проходит обучающий. Именно здесь задаётся педагогическая логика «сначала теория, потом проверка, потом практика в контейнере, в конце экзамен модуля»; при необходимости добавляются **опросы** для обратной связи.

> **Зачем этот раздел:** без явной структуры курс превращается в свалку страниц. Порядок drag-and-drop, переключатель **Включён** и копирование разделов с первого модуля ускоряют сборку типового потока по ОС «Альт» и другим программам.

## Кому и когда нужно

Модератору и тестировщику — при сборке и приёмке модуля. Инструктору раздел недоступен для правки. Открывайте вкладку после создания курса и перед каждым релизом нового модуля в опубликованный поток.

## Что вы делаете здесь и какой результат ожидать

Вы добавляете модули с буквой и **пакетом контента**, упорядочиваете их и разделы, включаете/отключаете этапы и открываете редакторы (`>`). Результат — на хабе модуля у обучающегося отображается согласованная цепочка этапов с правильными цветами и названиями.

## Пошаговая работа

1. **Откройте курс** → вкладка **Модули**.
2. **Добавьте модуль:** **+ Добавить модуль** → название, **Буква** (A, B, …), **Пакет контента №** (если теория/тесты подтягиваются из конфигурации), **Описание для обучающихся** для карточки на хабе.
3. **Первый модуль** получает стандартный набор из **четырёх разделов**; следующие модули могут **скопировать** разделы с первого — сэкономьте время, затем поправьте названия и контент.
4. **Перетащите модули** (`=` или drag-and-drop), нажмите **Сохранить порядок** — порядок влияет на нумерацию M1, M2 в отчётах.
5. **Внутри модуля** упорядочите разделы, включите **Включён** только для готовых этапов, откройте редактор через `>`.
6. **Добавьте раздел** при нестандартной схеме (**+ Добавить раздел**), **Сохранить порядок разделов** после перестановки.
7. **Пригласите соавторов** на отдельные модули или разделы — вкладка **Соавторы** рядом с **Модули** (см. [Соавторы курса](/docs/admin/collaborators)).

## Частые вопросы

**Отключил раздел — пропал ли прогресс у студентов?** Прогресс в БД обычно сохраняется; этап может скрыться с хаба. Согласуйте отключение с активным потоком.

**Зачем копировать разделы с первого модуля?** Чтобы не создавать вручную стандартный набор в каждом модуле курса с одинаковой структурой.

**Сколько разделов одного типа можно добавить?** Неограниченно: например, три блока теории или несколько опросов в одном модуле — каждый со своим названием и контентом.

**Пакет контента перезаписал мои правки?** Импорт из конфигурации целесообразен на **первом** наполнении; дальше правьте в редакторах и не переимпортируйте без бэкапа.

> **Подсказка:** типовой модуль курса по администрированию ОС: теория → тест по теории → практика с `check.sh` → экзамен с увеличенным временем (настраивается в разделе теста).
