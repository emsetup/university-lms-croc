## О чём эта инструкция

Вкладка **Вопросы** — сердце проверки знаний: формулировки, варианты ответов, типы (один/несколько правильных, сопоставление), порядок показа. Качество банка напрямую влияет на справедливость баллов в формуле курса (теория / тест / практика / экзамен).

> **Зачем этот раздел:** настройки времени и проходного балла бессмысленны без вопросов. Редактирование — в **Модули** (вкладка **Вопросы** у раздела); приёмка — на **Содержимое** (**Просмотр**).

## Кому и когда нужно

Модератору при первичном наполнении из пакета контента; тестировщику при ревизии перед публикацией. Открытие: **Модули** → **Тест** / **Экзамен** → `>` → **Вопросы**.

## Что вы делаете здесь и какой результат ожидать

Вы добавляете и упорядочиваете вопросы, отмечаете правильные ответы, сохраняете в таблицы `course_quiz_*`. После сохранения **Просмотр** с вкладки **Содержимое** показывает тест как у обучающегося; при опубликованном курсе новые попытки используют обновлённый банк.

## Пошаговая работа

1. **Модули** → раздел **Тест** или **Экзамен** → `>`.
2. Перейдите на вкладку **Вопросы** (не «Настройки раздела»).
3. **Добавьте вопросы** или проверьте импорт из **пакета контента** при создании модуля.
4. Для каждого вопроса: текст (допускается Markdown, в т.ч. [картинки](/docs/admin/media-images)), варианты, отметьте **правильные**; для сопоставления — пары.
5. **Перетащите** вопросы в нужном педагогическом порядке (от простого к сложному).
6. **Сохраните** банк; задайте лимит времени в **Настройках раздела**, если ещё не задан.
7. **Просмотр** с **Содержимое** — финальная приёмка; тестировщик проходит тест как студент (impersonation при необходимости).

## Элементы интерфейса

| Элемент | Зачем нужен | Как пользоваться | Что произойдёт |
|---------|-------------|------------------|----------------|
| Добавить вопрос | Расширение банка | Кнопка новой строки | Пустой вопрос в списке |
| Текст вопроса | Формулировка | Markdown, код, кнопка **Картинка** | Отображение на попытке |
| Варианты ответа | Выбор студента | Поля + галочки правильных; у поля — иконка **Картинка** | Подсчёт балла |
| Тип «сопоставление» | Пары понятий | Заполнить пары | Специальная логика проверки |
| Порядок (drag) | Сложность по нарастанию | Перетаскивание | Порядок на попытке |
| Импорт / сид | Стартовый банк | Из конфигурации курса | Массовое наполнение |
| **Сохранить** | Запись в БД | После правок | Актуальный банк для портала |

## Частые вопросы

**Вопрос с несколькими правильными — как оценивается?** Зависит от настроек типа вопроса в редакторе; при приёмке пройдите тест сами и сверьте балл с ожиданием.

**Импорт затёр ручные правки.** Делайте импорт один раз при создании модуля; дальше версионируйте правки через экспорт/бэкап процессов команды (вне портала).

**Markdown в вопросе ломает вёрстку.** Проверьте незакрытые ``` и спецсимволы; используйте **Просмотр**.

> **Подсказка:** для итогового теста модуля согласуйте число вопросов с лимитом времени в **Настройках раздела** — ~1–2 минуты на вопрос с кодом это ориентир, не догма.
