## О чём эта инструкция

Тип раздела **Опрос** — инструмент сбора обратной связи и данных внутри модуля курса: анкеты, NPS, короткие опросы после практики. Вопросы могут быть с вариантами ответа, сопоставлением пар, **открытым текстом** и **смешанным** форматом (несколько вариантов + свой текст). Оценка и проверка правильности **не проводятся**, но обучающийся должен отправить ответы, чтобы перейти к следующим разделам (если включена блокировка прогресса).

> **Зачем этот раздел:** опросы живут в той же цепочке модуля, что теория и тесты — не нужны внешние формы. Ответы хранятся в портале, их можно смотреть в таблице и выгружать в Excel для анализа в таблицах.

## Кому и когда нужно

**Создавать и редактировать** опросы могут администратор портала, модератор курсов, создатель и редактор курса (на своих или назначенных курсах). **Смотреть ответы и выгружать** — также инструктор на назначенных курсах (см. [Опросы для сотрудников](/docs/staff/survey)). Тестировщик курса не заходит в настройки модулей — проверяет сценарий через **Просмотр** обучающегося.

Открывайте эту инструкцию при добавлении первого опроса в модуль и перед выгрузкой данных для отчёта.

## Что вы делаете здесь и какой результат ожидать

Вы добавляете один или несколько разделов «Опрос» в модуль, наполняете вопросами, при необходимости включаете анонимность. Обучающиеся проходят опрос по одному вопросу на экран. После отправки ответы появляются во вкладке **Опросы** курса, в таблице раздела и в карточке обучающегося; их можно скачать в **CSV** или **Excel**.

## Пошаговая работа

### 1. Создать раздел «Опрос»

1. Откройте курс → вкладка **Модули**.
2. В нужном модуле нажмите **+ Добавить раздел**.
3. В модалке выберите тип **Опрос** (фиолетовая карточка).
4. Задайте **Название раздела** (например, «Опрос о важном» или «Обратная связь после практики»).
5. Нажмите **Создать раздел**.

![Создание раздела «Опрос»](/images/docs/admin-survey-create-modal.png)

В одном модуле можно добавить **несколько** опросов — например, анкету в начале и опрос в конце. Ограничения «один опрос на модуль» нет.

### 2. Наполнить вопросами

1. В списке разделов модуля откройте редактор опроса (стрелка `>` или клик по строке).
2. Вкладка **Вопросы** — добавьте вопросы, задайте порядок (drag-and-drop).
3. Для **открытого ответа**: тип **Открытый ответ**, текст вопроса, при желании **Подсказка в поле** и **Макс. длина ответа** (по умолчанию до 8000 символов).
4. Для **смешанного** — см. раздел ниже.
5. Также доступны типы с вариантами (один/несколько) и сопоставление — как в тестах, но без зачёта баллов.
6. **Сохранить изменения**.

![Редактор вопросов опроса](/images/docs/admin-survey-questions.png)

### Смешанный вопрос (варианты + свой текст)

Тип **Смешанный** доступен **только в опросах** (не в тестах и не в экзамене). Респондент видит чекбоксы готовых вариантов и поле **Свой вариант**: можно отметить варианты, вписать свой текст или сделать и то и другое.

![Редактор смешанного вопроса](/images/docs/admin-survey-mixed-question.png)

**Как настроить в редакторе**

1. Тип вопроса → **Смешанный**.
2. **Текст вопроса** — формулировка; рядом кнопка картинки ([библиотека](/docs/admin/media-images)).
3. **Варианты ответов** — список пунктов (как у «несколько ответов»). У каждого варианта своя кнопка картинки. Правильных ответов нет — опрос без оценки.
4. **Подсказка в поле «Свой вариант» / открытый ответ** — плейсхолдер в текстовом поле у респондента (например: «Опишите кратко…»).
5. **Макс. длина своего / открытого ответа** — лимит символов (часто 8000).

**Как выглядит у обучающегося:** чекбоксы + поле ввода «Свой вариант».

**Как выглядит в отчётах:** в **Сводной**, **По ответам** и Excel/CSV ответ собирается в строку вида `Вариант 1, Вариант 2; свой вариант: …` (если свой текст пуст — только выбранные варианты).

> **Подсказка:** смешанный тип удобен, когда нужен готовый список причин и возможность дописать «другое» без отдельного открытого вопроса.

### 3. Настройки раздела

Вкладка **Настройки раздела**:

| Параметр | По умолчанию | Зачем |
|----------|----------------|-------|
| Время | не ограничено | Лимит на прохождение (редко нужен для опроса) |
| Попытки | 1 | Повторная отправка недоступна |
| **Анонимный опрос** | выкл. | В отчётах не показывается ФИО/email респондента |
| **Блокирует следующие разделы** | вкл. | Без отправки опроса нельзя открыть следующие этапы модуля |

### Быстрая ссылка на опрос

**Быстрая ссылка** — отдельный сценарий: по адресу вида `/opros/…` обучающийся входит в портал, проходит **только этот опрос** и видит «Спасибо», без хаба модуля и без проверки последовательности курса.

**Где создать:** кнопка **Поделиться** у раздела опроса (в списке разделов или в шапке панели редактора) → в модалке **Включить ссылку** → **Копировать**. Можно **перевыпустить** (старая перестанет работать) или **выключить**. Все ссылки курса также собраны на вкладке настроек **Ссылки** (рядом с **О курсе**).

Доступ по ссылке только для **авторизованных** с доступом к курсу. У опросов с активной ссылкой на вкладке **Опросы** курса есть пометка **быстрая ссылка**.

Для свободного прохождения курса без последовательности включите в настройках курса **Все модули доступны сразу**; для необязательного опроса в цепочке модуля выключите **Блокирует переход к следующим разделам**.

### 4. Просмотр ответов по одному разделу

В панели редактора раздела — вкладка **Участники**: кто имеет доступ, кто прошёл и кто ещё нет. При ограниченном доступе — полный список допущенных со статусами; при открытом для всех — только прошедшие. Клик по участнику открывает его ответы. Там же ссылка **Открыть на странице** и (для опросов) **Сводная / CSV**.

Либо из контекста модуля: ссылка **Ответы опроса и выгрузка CSV** / **Участники раздела**. Таблица ответов: строки — обучающиеся (если не анонимно), столбцы — вопросы. Кнопка **Скачать CSV** — файл для Excel или Google Таблиц. С вкладки **Опросы** курса — кнопка **Участники** ведёт на тот же список.

### 5. Сводка по всем опросам курса

1. В шапке курса откройте вкладку **Опросы** (появляется, если в курсе есть хотя бы один опрос).
2. Слева — список опросов по модулям с числом ответов; у опросов с активной быстрой ссылкой — пометка **быстрая ссылка**.
3. Справа — сводная таблица с вкладками:
   - **По ответам** — каждая строка один ответ на один вопрос (удобно читать открытый текст);
   - **Сводная** — одна строка на респондента, столбцы — вопросы (удобно для фильтров в Excel).
4. Кнопки **Excel: сводная** и **Excel: по строкам** — выгрузка в `.xls` для анализа.

### 6. Ответы в карточке обучающегося

Вкладка **Обучающиеся** → карточка участника → отчёт по модулю. Для каждого опроса — отдельный блок: дата отправки и список ответов (или «ещё не отправил»). Для анонимного опроса в карточке текст ответов скрыт, видна только факт отправки.

## Кто что может

| Роль | Создать / редактировать опрос | Смотреть ответы, CSV, Excel |
|------|------------------------------|-----------------------------|
| Администратор портала | да | да |
| Модератор курсов | да | да |
| Создатель / Редактор курса | да (свои и назначенные курсы) | да |
| Инструктор | нет | да (назначенные курсы) |
| Тестировщик курса | нет (нет доступа к **Модули** в настройках) | нет вкладки **Опросы**; проверка через **Просмотр** как у обучающегося |

## Частые вопросы

**Обучающийся не видит опрос на хабе.** Проверьте, что раздел **Включён** и стоит в нужном порядке; предыдущие обязательные этапы должны быть завершены.

**В опросе 0 вопросов — что увидит студент?** Редирект на хаб с сообщением, что вопросов нет. Добавьте хотя бы один вопрос перед публикацией потока.

**Нужны два опроса в одном модуле.** Добавьте два раздела типа **Опрос** с разными названиями; у каждого свой банк вопросов и своя выгрузка.

**Анонимный опрос — видно ли, кто ответил?** В таблицах и Excel нет привязки к email; в карточке обучающегося текст ответов скрыт, отображается только факт участия.

**Чем CSV отличается от Excel на вкладке «Опросы»?** CSV — быстрая выгрузка одного раздела из редактора. Excel на вкладке **Опросы** — сводные форматы по курсу (широкая и длинная таблица), удобны для сводной статистики по всем респондентам.

**Где быстрая ссылка на опрос?** Кнопка **Поделиться** у раздела опроса или вкладка **Ссылки** в настройках курса (рядом с **О курсе**). В поиске справки наберите «быстрая ссылка».

> **Подсказка:** для открытых вопросов используйте вкладку **По ответам** на странице **Опросы** — так проще читать развёрнутые комментарии, чем в широкой таблице.
