## О чём эта инструкция

Редактор **Теории** (и задания практики) — место, где вы пишете учебный текст в **Markdown** с визуальной панелью: заголовки, списки, код, ссылки, **таблицы**, **картинки**, диаграммы **Mermaid** и цветные **плашки** в стиле документации. У обучающегося текст выглядит так же, как в **Preview**.

> **Зачем этот раздел:** один редактор в панели **Модули** и на страницах контента — без правки файлов на диске и без знания всей разметки наизусть: плашки и таблицы вставляются кнопками.

## Кому и когда нужно

Модератору, редактору и соавтору при наполнении модуля. Открывается из **Модули** → строка **Теория** (или **Практика**) → `>`. Перед публикацией сверьте вид через **Preview** в редакторе или **Содержимое** → **Просмотр**.

## Что вы делаете здесь и какой результат ожидать

На вкладке **Содержимое** пишете и оформляете текст, при необходимости меняете название и активность на **Настройки раздела**, сохраняете. После сохранения обучающийся видит обновлённую теорию (если раздел **Включён** и курс доступен потоку).

## Пошаговая работа

1. **Модули** → **Теория** → `>` — боковая панель редактора.
2. На вкладке **Содержимое** набирайте текст; структуру задавайте кнопками панели (см. ниже).
3. Плашки — кнопки **Важно** / **Подсказка** / **Примечание** / **Зачем** (или вручную цитатой).
4. Таблицы — **Table**; картинки — иконка изображения ([библиотека](/docs/admin/media-images)); схемы — **Mermaid**.
5. **Preview** или **Side-by-side** — вид как у студента (включая цвет плашек).
6. Следите за счётчиком символов внизу панели.
7. **Настройки раздела** — название на хабе, тип, **Активен**.
8. **Сохранить изменения**. **Отмена** закрывает без записи.
9. **Скачать Word** — в шапке панели раздела (и внизу вкладки Содержимое); копия теории для ревью или печати (см. [экспорт](/docs/admin/export-content)).
10. Дополнительная проверка: **Содержимое** курса → **Просмотр**.

## Кнопки панели — что означают

![Расширенный редактор теории с плашками](/images/docs/admin-theory-editor.png)

### Форматирование текста

| Кнопка | Значение | Результат |
|--------|----------|-----------|
| **B** | Жирный | `**текст**` |
| *I* | Курсив | `*текст*` |
| **Заголовок** | Крупный заголовок с **зелёной полоской** слева | `## Текст` — как в теории у обучающегося |
| **Подзаголовок** | Меньший заголовок с полоской | `### Текст` |
| **≡ Центр** | Текст по центру, полоска **снизу** | `## {center} Текст` |
| **≡ \| Центр** | Текст по центру, полоска **слева** (как у обычного заголовка) | `## {center-bar} Текст` |
| **Оглавление** | Блок содержания в **начало** текста | `[[toc]]` — кликабельные ссылки на все `##` / `###` |
| «кавычки» | Цитата | `> …` (без метки станет обычной плашкой «Примечание») |
| Список | Маркированный | `- пункт` |
| Нумерованный список | Нумерация | `1. пункт` |
| Ссылка | Гиперссылка | `[текст](url)` |
| Картинка | [Библиотека картинок](/docs/admin/media-images) | `![…](/media/…)` |
| `</>` | Код | `` `команда` `` или блок кода |
| Таблица | Таблица GFM | сетка Markdown |

Выделите текст и нажмите **Заголовок** — строка станет `## …`. Или поставьте курсор на пустую строку: вставится шаблон, текст можно сразу перепечатать. Выравнивание: **≡ Центр** (полоска снизу) или **≡ | Центр** (текст по центру + полоска слева). Повторный клик снимает.

**Оглавление:** кнопка **Оглавление** вставляет в начало документа маркер `[[toc]]`. У обучающегося (и в Preview) на его месте появляется блок «Оглавление» со ссылками на все заголовки `##` и `###`. Список **обновляется сам** при добавлении или переименовании заголовков — вручную править ссылки не нужно. Повторный клик снова ставит маркер в начало (дубликаты убираются). Можно написать `[[toc]]` или `[TOC]` вручную в любом месте текста.

### Плашки (цветные блоки)

| Кнопка | Когда использовать | Как выглядит у студента |
|--------|--------------------|-------------------------|
| **Важно** | Критичное ограничение, риск, запрет | Жёлтая плашка (предупреждение) |
| **Подсказка** | Практический совет, как сделать правильно | Зелёная плашка (совет) |
| **Примечание** | Доп. контекст, уточнение | Нейтральная / серо-зелёная плашка |
| **Зачем** | Цель раздела, идея, «зачем это нужно» | Зелёная плашка «цель / идея» |

Вставляется шаблон вида:

```markdown
> **Важно:** критичное ограничение или риск…
```

Другие метки, которые тоже распознаются без отдельной кнопки: **Критично**, **Идея модуля**, **Почему это важно**, **Практическое правило**.

### Диаграммы и предпросмотр

| Кнопка | Значение |
|--------|----------|
| **Mermaid** | Шаблон блока `` ```mermaid `` `` — схемы flowchart и др.; рисуются у студента и в Preview |
| **Preview** (глаз) | Полный предпросмотр HTML как у обучающегося; повторный клик или **Esc** — выход |
| **Side-by-side** | Редактор и предпросмотр рядом **внутри панели** (не на весь экран); повторный клик или **Esc** — выход. Кнопки **Сохранить** / **Отмена** остаются доступны |

## Плашки вручную

Если удобнее печатать самому:

```markdown
> **Важно:** не отключайте enforce в PAM без понимания последствий.

> **Подсказка:** параметр называется **`enforce`**.
```

Строка должна начинаться с `>` и содержать жирную метку `**Метка:**`.

## Элементы панели раздела

| Элемент | Зачем |
|---------|--------|
| Вкладка **Содержимое** | Текст теории / задания |
| **Настройки раздела** | Название, тип, активность |
| **Доступ** | Ограничение видимости для обучающихся |
| Счётчик символов / lines / words | Контроль объёма |
| **Скачать Word** | Выгрузка теории в `.doc` для ревью/печати |
| **Сохранить изменения** | Запись в БД |
| **Отмена** | Закрыть без сохранения |

## Частые вопросы

**Markdown из Word вставляется криво.** Очистите форматирование; списки и заголовки задайте явно (`-`, `##`) или кнопками панели. Обратная загрузка из `.doc` в портал не поддерживается — только [скачивание](/docs/admin/export-content).

**Сохранил, но студент видит старое.** Обновите страницу у обучающегося; проверьте **Включён** и статус курса для потока.

**Плашка не стала цветной.** Нужны `>` и метка вроде `**Важно:**`. Проверьте в **Preview**.

**Где ещё тот же редактор?** На странице **Контент модуля (БД)** и в классическом редакторе legacy-теории — те же кнопки плашек и Preview.

> **Подсказка:** пишите теорию с прицелом на следующий **Тест** — формулировки вопросов должны опираться на прочитанное.
