## О чём эта инструкция

В курсах с разделами **Опрос** ответы обучающихся собираются в портале. Эта статья для **инструктора** и других сотрудников, которым **не нужно** создавать опросы, но нужно **читать результаты** и выгружать данные. Редактирование вопросов и создание опросов — в [инструкции для редакторов курса](/docs/admin/survey) (раздел «Редактирование курсов» в документации).

> **Зачем этот раздел:** инструктор не заходит в **Модули** для правки контента, но имеет доступ к статистике по назначенным курсам — в том числе к опросам.

## Инструктор: как смотреть и выгружать ответы

### Вкладка «Опросы» в курсе

1. Войдите в **`/adm`** и откройте **назначенный** курс.
2. В шапке курса выберите вкладку **Опросы** (доступна, если в курсе есть опросы и у вас есть право смотреть статистику обучающихся).
3. Слева — список всех опросов по модулям с числом ответов.
4. Выберите опрос — справа таблица:
   - **По ответам** — удобно для открытого текста;
   - **Сводная** — одна строка на человека, столбцы — вопросы.
5. **Excel: сводная** и **Excel: по строкам** — скачать файл для анализа в Excel.

Контент опроса (вопросы, формулировки) **не редактируется** инструктором. Изменения — у модератора или редактора курса.

### Карточка обучающегося

1. Курс → **Обучающиеся** → строка участника → **Карточка**.
2. Откройте отчёт по модулю, где есть опрос.
3. В списке разделов найдите блок опроса: дата отправки и ответы по вопросам (или «ещё не отправил»).
4. Для **анонимного** опроса текст ответов в карточке скрыт — виден только факт участия.

### CSV по одному опросу

Полная выгрузка CSV из редактора раздела доступна **редакторам** курса. Инструктору достаточно вкладки **Опросы** и Excel; при необходимости файла CSV попросите модератора или редактора.

## Тестировщик курса

Тестировщик **не создаёт** опросы в **Модули** (нет доступа к настройкам курса). При приёмке модуля:

1. Откройте **Содержимое** → **Просмотр** этапа опроса или пройдите цепочку как обучающийся (impersonation / тестовая учётная запись).
2. Проверьте: все вопросы отображаются, открытый текст сохраняется, после отправки этап на хабе **Готово**, следующий раздел открывается.
3. Замечания по формулировкам передайте модератору или редактору.

## Кто что может (кратко)

| Роль | Создать опрос | Смотреть ответы / Excel |
|------|---------------|-------------------------|
| Инструктор | нет | да (назначенные курсы) |
| Тестировщик | нет | нет (только проверка через **Просмотр**) |
| Редактор / модератор | да | да |

Подробная таблица и пошаговое создание — в статье [Раздел «Опрос»](/docs/admin/survey) (видна редакторам курса в разделе документации «Редактирование курсов»).

## Частые вопросы

**Нет вкладки «Опросы».** В курсе ещё нет разделов типа опрос или у вашей роли нет права статистики по обучающимся на этом курсе. Уточните привязку к курсу у администратора портала.

**Ответов 0, хотя студенты проходили.** Убедитесь, что смотрите тот же опрос (в модуле может быть несколько). Проверьте, что раздел **Включён** и студенты нажали **Отправить**, а не только **Далее** на последнем вопросе.

> **Подсказка:** для регулярного мониторинга обратной связи выгружайте **Excel: по строкам** раз в неделю — формат удобен для фильтрации и поиска по открытым ответам.
