Пояснения к сложным вопросам

3. В режиме native пользователь управляет всем; в режиме etcnet через NM — только вкл/выкл, без смены IP без root.

8. ONBOOT=no не запрещает ручной ifup, только автоподъём при загрузке.

13. Удаление пакета NetworkManager не обязательно; достаточно mask.

19. При DISABLED=yes etcnet игнорирует интерфейс; остановка NM без смены options оставляет интерфейс без «хозяина».
