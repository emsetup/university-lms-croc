# Модуль 1. Ответы для методиста (не для слушателей)

Файл для сверки. Сайт BaseAlt меняется - при расхождении актуален **текущий** сайт.

---

## Тест A (открытые)

Проверяйте **логику**, не дословное совпадение.

1. **Пример корректных имён** (на момент оформления курса): у "Альт Сервер", "Альт Рабочая станция", "Альт Образование", "Альт Виртуализация" и др. на documentation часто есть блоки вроде "жизненный цикл" - слушатель должен назвать **два** продукта, которые он реально нашёл на сайте.

2. **Альт Платформа** - про **сборку** ПО / технологический комплекс, а не готовая ОС для установки в роли "сервер в продакшене" в том же смысле, что "Альт Сервер".

3. Продукт с **виртуализацией** в названии линейки - **"Альт Виртуализация"** (как на basealt.ru в продуктовой навигации).

## Тест C

Оценочные ориентиры:

1. Разные продукты и релизы имеют разный состав, сроки поддержки, регламенты - одна книга не покрывает сертифицированные и несертифицированные сценарии.

2. Документация - эксплуатация конкретной ОС; Академия - учебные треки и программы, это разные задачи и аудитории.

3. Ожидаемая мысль: разные роли (сервер, рабочая станция, образование, СП), разные требования по составу и сертификации - одна универсальная сборка не подходит под все контракты и регламенты.
